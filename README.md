## 项目简介

KarmaFlow 会在 Android 手机上监听和补扫银行短信，将其中的收入、支出、退款与交易后余额转换为本地账目，再根据当前银行卡余额、目标结余、预留项目和自定义预算周期计算每日可用额度。

项目的核心不是传统的“记完一笔再看总数”，而是回答三个更直接的问题：

- 今天还能花多少钱？
- 如果今天继续消费，明天预计还能花多少钱？
- 按现在的余额和速度，能否在周期结束时保留目标结余？

所有短信解析、余额管理和预算计算都在手机本地完成。当前版本不包含 AI、云同步、用户账户、广告或联网功能。

## 主要功能

### 银行短信自动记账

- 接收新银行短信后立即尝试解析，不需要一直打开应用。
- 授予读取短信权限后，可补扫最近 45 天内支持银行的短信。
- 识别收入、支出、退款、交易冲正和交易后余额。
- 过滤验证码、动态口令、失败交易、登录提醒和无明确收支信号的通知。
- 使用短信指纹和 Room 唯一索引双重去重，重复补扫不会重复入账。
- 不保存完整短信正文，只保留预算所需的结构化字段。

### 支持的银行

| 银行 | 常用短信号码 | 当前范围 |
| --- | --- | --- |
| 中国工商银行 | 95588 | 借记卡收支、退款、余额 |
| 中国建设银行 | 95533 | 借记卡收支、退款、余额 |
| 中国农业银行 | 95599 | 借记卡收支、退款、余额 |
| 中国银行 | 95566 | 借记卡、部分信用卡与外币消费 |
| 招商银行 | 95555 | 一卡通收支、退款、余额 |
| 交通银行 | 95559 | 借记卡收支、退款、余额 |
| 邮储银行 | 95580 | 借记卡收支、退款、余额 |

短信号码可能带有国家代码、地区前缀或运营商长号码。解析器会同时结合发送号码和短信中的银行签名判断来源。

### 银行账户与余额

- 左侧侧栏按银行显示账户，没有识别到的银行不会出现。
- 当前采用“一家银行一个账户”的展示方式，不识别或显示卡尾号。
- 同一家银行有多张卡时，余额使用该银行最新一条带余额短信的数值。
- 首页显示所有已识别银行的合计余额。
- 支持手动编辑总余额；时间更新的银行余额短信到达后可自动更新。

### 预算周期与每日额度

- 周期起始日期和终止日期可分别设置，不要求按自然月计算。
- 默认预留项目为房租 `¥2,400`、租车 `¥300`，可新增、编辑或删除。
- 支持设置周期起始余额，用于显示原计划每日额度。
- 支持设置目标结余，目标结余没有人为上限。
- 当目标结余和预留金额高于余额时，今日可用和明日预计允许显示负数。
- 预算以当前银行卡余额为基础，不再使用“每周期总预算”作为计算来源。

### 今日可用与明日预知

- “今日可用”每天第一次计算后保持锁定，当天消费不会让这个数字不断变化。
- 到第二天后，应用会按最新余额、目标结余、预留项目和剩余天数重新计算。
- 可以点击“刷新额度”，主动使用最新余额重新锁定当天额度。
- “今日已消费”会随真实支出正常变化。
- “明日预计可花”会根据今天的实际消费动态变化。
- “今日消费预览”支持 `¥0–¥2,000` 滑块和手动输入，用来观察继续消费后明日额度的变化，不会修改真实账目。

### 固定预算通知

- 下拉通知栏默认只显示“今日已消费”。
- 左侧侧栏提供“通知栏摘要”设置，可随时关闭固定通知或自定义显示内容。
- 可选内容包括今日已消费、今日可用、明日预计可花、当前余额、本期已消费、可分配余额、目标结余、预留金额和周期剩余天数。
- 通知会随短信入账、余额和预算配置变化自动刷新，并在跨日后重新计算。
- 通知为低打扰、静音样式，不包含操作按钮或额外财务信息。
- Android 13 及以上首次使用时需要允许通知权限。

### 消费趋势

- 显示当前周期最近 31 天的数据。
- 同时绘制“每日预计花费”和“每日实际花费”两条曲线。
- 显示实际日均、最高单日消费和日期范围。
- 人民币以外的交易保留原币种显示，不混入人民币预算曲线。

### 历史收支明细

- 按时间倒序显示本地收入、支出和退款。
- 展示银行、交易说明、时间、币种和金额。
- 每笔记录可选择“取消计入”，但不会删除原始结构化记录。
- 被取消的记录不参与今日消费、周期统计或曲线计算。
- 可以随时恢复计入；短信指纹仍会防止补扫时重复导入。

## 计算逻辑

KarmaFlow 的额度主要由以下数据共同决定：

1. 当前银行卡合计余额。
2. 周期结束时希望保留的目标结余。
3. 房租、租车等预留项目。
4. 当前日期距离周期结束日期的剩余天数。
5. 当天已发生的人民币净消费。

“原计划每日额度”使用周期起始余额和整个周期天数计算；“今日可用”使用当天锁定余额和剩余天数计算；“明日预计可花”则在当前余额基础上继续扣除消费预览金额，再按明天开始的剩余天数计算。

目标结余与预留项目不会被当作可消费金额进行平均分配。

## 安装与使用

1. 从 GitHub Releases 下载最新 APK。
2. 在 Android 系统中允许当前文件管理器或浏览器“安装未知应用”。
3. 安装并打开 KarmaFlow。
4. 授予“接收短信”权限，用于监听之后收到的银行短信。
5. 如需补记历史短信，再授予“读取短信”权限并在侧栏点击同步。
6. 设置周期起止日期、目标结余和预留项目。
7. 核对第一笔真实收支的金额、类型和余额是否正确。

从旧版本覆盖安装时，Room 数据库和预算配置会保留。请不要在升级前卸载旧版本，否则 Android 会同时删除应用的本地数据。

### HyperOS / MIUI 提示

部分小米系统会限制后台广播。建议在系统应用设置中确认：

- 短信权限已允许。
- KarmaFlow 未被强制停止。
- 如实时监听经常延迟，可允许自启动并减少电池优化限制。
- 授予读取短信权限后，即使后台广播偶尔延迟，再次打开应用也会自动补扫遗漏记录。

Android 对被用户“强制停止”的应用会暂停广播接收，这是系统行为，任何应用都无法绕过。

## 隐私与权限

KarmaFlow 1.22.2 不包含 `INTERNET` 或 `ACCESS_NETWORK_STATE` 权限。

| 权限 | 用途 |
| --- | --- |
| `RECEIVE_SMS` | 实时接收并解析新到达的银行短信 |
| `READ_SMS` | 经用户授权后补扫最近 45 天的支持银行短信 |
| `WAKE_LOCK` | WorkManager 执行短时间后台任务 |
| `RECEIVE_BOOT_COMPLETED` | 系统重启后恢复安全补扫计划 |
| `FOREGROUND_SERVICE` | Android 后台任务框架兼容权限 |

隐私原则：

- 不上传账目、余额或短信内容。
- 不保存完整短信正文、验证码或完整卡号。
- 不识别或展示卡尾号。
- 不包含统计 SDK、广告 SDK 或远程日志服务。
- 禁止 Android 系统备份应用数据。
- 旧版曾保存的 DeepSeek API Key 会在升级到 1.22.2 后自动删除。

├── data/          Room 数据库、账户余额与预算配置

数据链路：

```text
银行短信
  → BankSmsReceiver / SmsInboxSynchronizer
  → BankSmsParser

  → BudgetCalculator
  → Jetpack Compose 首页
```

## 已知限制

- 银行短信格式可能随地区、卡种、语言或银行系统升级发生变化，无法保证覆盖所有模板。
- 一家银行固定显示为一个账户，因此不会区分该银行下的多张卡。
- 余额来自银行短信中的“交易后余额”；没有余额字段的短信只能记录收支，不能更新余额。
- 外币交易不会自动换算成人民币，也不会混入人民币预算。
- 应用无法在被系统强制停止期间继续监听短信。
- 当前没有云同步，多设备之间不会自动共享数据。

如遇到未识别短信，请先隐藏姓名、完整卡号、余额和验证码，再提交脱敏后的短信模板。

- 支持用户手动编辑账户余额。
- 预算计算开始以余额作为重要输入。

### 1.3.0 — 本月已省下

- 增加“本月已省下”统计。
- 按每天预计花费与实际花费的差额累计。
- 该功能后来在 1.8.0 中移除，改为目标结余。

### 1.2.1 — 自定义起止日期

- 预算周期支持独立设置起始日期和终止日期。
- 修复只设置周期长度时与真实预算周期不一致的问题。

### 1.2.0 — 自定义预算

- 月度总预算可编辑，默认 `¥8,888`。
- 房租 `¥2,400` 和租车 `¥300` 改为可编辑配置。
- 增加自定义预算周期设置。

### 1.1.0 — HyperOS 兼容与同步

- 增强小米 HyperOS 环境下的短信监听说明与权限处理。
- 增加历史短信读取和主动同步能力。
- 应用重新回到前台时自动补扫，弥补后台广播延迟。

### 1.0.2 — 中国银行真实格式适配

- 适配“借记卡账户…网上支付支取人民币…交易后余额”的真实短信格式。
- 增加金额、日期和交易后余额提取。

### 1.0.1 — 95566 发送号码修正

- 修复仅根据短信正文判断、导致 95566 消息未触发记账的问题。
- 增加对中国银行服务号码 95566 的识别。

### 1.0.0 — 首个可运行版本

- 建立 Kotlin、Jetpack Compose 和 Room 项目。
- 使用 `BroadcastReceiver` 接收银行短信。
- 首版支持中国银行消费短信解析、去重和本地入账。
- 显示今日消费、本月消费、本月剩余和动态今日可支配金额。
- 默认预算 `¥8,888`，预留房租 `¥2,400`、租车 `¥300`。

## 项目定位

KarmaFlow 当前是面向个人使用的本地工具，不是银行官方应用，也不与任何银行建立接口连接。请始终以银行 App、银行账单和账户真实余额为最终依据。
