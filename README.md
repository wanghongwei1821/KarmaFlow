# KarmaFlow（Android）

一个完全本地运行的私人记账 App。收到银行消费短信后，App 在手机上解析金额、商户、卡尾号和时间，并写入 Room 数据库；不联网，也不保存完整短信正文。

## 当前能力

- 优先识别中国银行（`95566`、短信内含“中国银行/中行/BOC”）
- 支持信用卡外币消费（例如 HKD），按原币显示且不混入人民币预算统计
- 识别消费、支付、扣款、POS/银联交易、出账、取现，以及退款/退货/冲正
- 忽略验证码、登录提醒、余额查询和还款；收入/转入会单独记为收入且不计入消费
- 首页显示最近一次短信接收和解析状态，不保存短信正文
- HyperOS 等系统若拦截实时广播，可由用户主动同步最近 45 天的 95566 短信补漏
- SHA-256 指纹 + Room 唯一索引双重去重
- 每周期总预算可编辑，周期开始日期和终止日期可分别选择
- 预留项目可自由新增、改名、改金额和删除；默认保留房租 2400、租车 300 元
- 显示今日净消费、本周期净消费、周期剩余和动态“今日可支配”
- 可设置目标结余；目标结余不会分配到每日可花额度
- 短信权限、监听状态和历史同步集中在侧栏，首页保持简洁
- 全新资产总览设计：突出每日可花，轻量显示今日已消费，余额与周期合并展示
- 自动读取 95566 短信中的“交易后余额”，按短信时间保留最新余额，也可在首页手动修改
- 可设置周期起始余额：原计划每天为起始余额÷周期总天数，当前每天可花为最新余额÷剩余天数

## 构建

使用 Android Studio（JDK 17、Android SDK 35）打开本目录，等待依赖同步后运行 `app`。命令行构建：

```text
gradlew.bat assembleDebug
```

生成的调试安装包位于 `app/build/outputs/apk/debug/app-debug.apk`。

## 隐私与权限

实时监听使用 `RECEIVE_SMS`。仅当用户主动点击“同步最近中行短信”时申请 `READ_SMS`，并只查询最近 45 天发件号码含 `95566` 的短信。短信解析在本机完成；数据库只保存解析字段和不可逆指纹。项目没有网络权限，应用也禁止明文网络流量与系统备份。

> 短信格式会随银行和卡种变化。建议首次收到真实短信后核对一笔；如未识别，可在不提供完整卡号、余额或验证码的前提下补充脱敏模板来扩展规则。
